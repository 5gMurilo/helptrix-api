# docs

## Purpose
Auto-generated Swagger/OpenAPI documentation and project specification documents. The `docs.go`, `swagger.json`, and `swagger.yaml` files are generated by `swag init -g app/main.go` — do not edit them manually. The `app-specs/` subdirectory contains hand-written architecture and feature documentation.

## Key Files

| File | Description |
|------|-------------|
| `docs.go` | Auto-generated Go source embedding the Swagger spec |
| `swagger.json` | Auto-generated OpenAPI 3.0 spec in JSON format |
| `swagger.yaml` | Auto-generated OpenAPI 3.0 spec in YAML format |

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `app-specs/` | Hand-written architecture, feature, and database modeling docs (see `app-specs/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- Never edit `docs.go`, `swagger.json`, or `swagger.yaml` directly — always regenerate with `swag init -g app/main.go`
- All endpoint handlers must have complete swaggo annotations before regenerating
- Swagger UI is served at `/swagger/index.html` when the server is running

### Testing Requirements
- After modifying any handler annotations, regenerate docs and verify the spec parses without errors
